# 보이싱 판독기

기타 지판이나 피아노 건반에서 음을 찍으면 그 보이싱의 코드 이름을 알려주는 PWA입니다. 의존성 없는 순수 HTML/JS라 빌드가 필요 없습니다.

**바로 쓰기: https://whgur7513-dotcom.github.io/voicing-reader/**
아이폰 Safari에서 열고 공유 버튼 → "홈 화면에 추가"를 누르세요. 한 번 열어 두면 오프라인에서도 동작합니다.

수정한 뒤 다시 올리려면 이 폴더에서 `git add -A && git commit -m "수정" && git push` 를 실행하면 1~2분 뒤 반영됩니다.

| 파일 | 역할 |
|---|---|
| `chord.js` | 코드 판별 엔진 (템플릿 매칭, 점수, 철자) |
| `app.js` | 화면(지판·건반·결과 카드), Web Audio 소리, localStorage 저장 |
| `index.html`, `style.css` | 페이지와 스타일 (라이트/다크) |
| `manifest.webmanifest`, `sw.js`, `icons/` | 홈 화면 추가·오프라인용 |
| `tests/` | 판별 로직 단위 테스트 |

## 코드 악보 만들기

1. 기타·피아노 화면에서 코드를 찍고 결과 카드의 **＋** 버튼을 누르면 악보에 차례로 담깁니다.
2. **악보** 탭에서 제목을 입력하고, 칸을 탭하면 ◀ ▶(순서 바꾸기)·불러오기·삭제를 할 수 있습니다.
3. **가사**: "가사 입력"을 눌러 가사를 쓰고 "완료"를 누릅니다. 글자를 탭하면 아래에 담은 코드 목록이 뜨고, 고른 코드가 그 글자 위에 붙습니다. "다이어그램"을 켜면 코드 이름 아래에 코드표도 함께 나옵니다.
4. **코드 설명**: 결과 카드의 "코드 설명 보기"를 누르면 코드의 구성·느낌·쓰임, 슬래시 코드·텐션·5음 생략에 대한 설명이 나옵니다.
5. **PDF로 저장**: 인쇄 화면이 열리면 아이폰에서는 공유(↑) → "파일에 저장"을 누르면 PDF로 저장됩니다. Mac에서는 인쇄 창 왼쪽 아래 "PDF" → "PDF로 저장"을 누르세요.
4. **이미지로 저장**: 악보 전체를 PNG 한 장으로 만듭니다. 이미지를 길게 눌러 "사진에 저장"하거나 "공유 / 저장"을 누르세요.

## 테스트 실행

```bash
/System/Library/Frameworks/JavaScriptCore.framework/Versions/A/Helpers/jsc chord.js tests/chord.test.js
```

브라우저에서는 `http://<주소>:8765/tests/` 를 열어도 같은 결과가 나옵니다.

## 아이폰에서 열기 (같은 Wi‑Fi)

1. Mac에서 이 폴더로 이동해 서버를 켭니다.
   ```bash
   python3 -m http.server 8765 --bind 0.0.0.0
   ```
   처음 실행하면 macOS가 "들어오는 연결 허용"을 물을 수 있습니다. 허용을 누르세요.
2. 아이폰이 Mac과 **같은 Wi‑Fi**에 연결돼 있는지 확인합니다.
3. 아이폰 Safari에서 `http://192.168.0.10:8765` 를 엽니다.
   (Mac의 IP는 바뀔 수 있습니다. `ipconfig getifaddr en0` 로 다시 확인하세요. `http://sin-ui-MacBookAir.local:8765` 도 대부분 동작합니다.)

## 홈 화면에 추가하기

1. Safari 아래쪽(또는 주소창 옆)의 **공유 버튼**(네모에서 화살표가 올라가는 아이콘)을 누릅니다.
2. 목록을 내려 **"홈 화면에 추가"** 를 누릅니다.
3. 이름("보이싱")을 확인하고 **추가**를 누르면 홈 화면에 아이콘이 생깁니다. 아이콘으로 열면 주소창 없이 앱처럼 전체 화면으로 열립니다.

참고:
- 로컬 주소(http)로 추가한 경우 **Mac 서버가 켜져 있을 때만** 열립니다. 언제 어디서나 쓰려면 GitHub Pages·Netlify·Cloudflare Pages 같은 무료 HTTPS 호스팅에 이 폴더를 그대로 올리면 됩니다. HTTPS에서는 서비스 워커가 켜져 한 번 연 뒤 오프라인에서도 동작합니다.
- 무음 스위치를 켜도 소리가 나도록 설정돼 있습니다(iOS 17 이상의 `navigator.audioSession`). 소리가 안 나면 볼륨을 올리고 화면을 한 번 탭해 보세요.
